### P1. What silicon does (RM0433 Rev 9, the pages above)
- **`NACKF`** is set at the ninth SCL pulse of the address byte (p1954, p2011), so the address phase lasts at least nine SCL periods after the START, each at least `[(SCLH+1) + (SCLL+1)] × (PRESC+1) × tI2CCLK` (p1971), plus `tSYNC1 + tSYNC2`, which RM0433 gives only by their causes (slopes, filters, two to three kernel clocks).
- **A STOP follows a NACK automatically, whatever `AUTOEND`** (p1975 is unconditioned). The WO's "with `AUTOEND` = 0 the bus waits" (from memory) is, I predict, not what the text says. `STOPF` is set once that STOP is on the bus (p2011: "the STOP condition is generated by the peripheral"), so after `NACKF`, by at least the STOP's own timing.
- **`TXIS` is not set** (p1975). **`TXE` and a `TXDR` flush on a NACK:** from memory, a NACK flushes `TXDR` and sets `TXE`; I expect the text not to say so in the controller section (§1 reads it).
- **`NACKIE`** gates `NACKF` onto the event interrupt (p1999).
- **A read transfer whose address is NACKed:** `NACKF` by p2011 (the address is a byte the controller transmits); the automatic STOP is stated only for the transmitter (p1975). I expect no sentence for the receiver.

### P3. ArduPilot (the fixture, 5 s; the armed run, 13 s)
- **The absent starts are `1306`'s:** `i2c1` `0x30`, `0x38`, `0x39`, `0x54`, `0x55`, `0x76`, and in the armed run `i2c2` the same less `0x76`; each a write with `AUTOEND` = 0 and `RELOAD` = 0 (a register address, then a read by repeated START); three attempts a transfer.
- **Next, today:** no interrupt; ChibiOS's timeout (milliseconds), `CR2 |= STOP` (which the guard passes: the port is still in controller mode after an absent start), `i2cSoftStop`, an SDA check and perhaps a GPIO bus clear, then `i2cStart` (`PE` cleared, `I2C1RST` pulsed, `CR1` = `0x90`, `TIMINGR`, `CR1` = `0x91`) and the next attempt.
- **Next, with a NACK modeled:** the event interrupt (`NACKIE`); `ISR` read; `ICR` = `0x10` (or `0x30` if `STOPF` is already set); `CR2 |= STOP`; `CR1 &= ~(TCIE | TXIE | RXIE)`; then the next attempt at once, with no bus clear.
- **The guard's own rule bites:** if the model sets `STOPF` at the same instant as `NACKF`, ChibiOS's `ICR` write clears both and its `CR2 |= STOP` then refuses `TVI-I2C-TRANSFER` ("STOP with no transfer", `1306`'s F2), on every probe. A `STOPF` set after the address phase and the STOP's time, as silicon, lets the STOP land while the port is still a controller. High confidence that the zero-time model refuses; moderate that a timed one passes.
- **ArduPilot's timeline moves:** each absent probe costs microseconds, not a timeout, so its probes end sooner and more of the 5 s window is reached. The armed run still arms. Its BMP581 transfers stay as they were, in content.
